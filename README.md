# FenneStore

Proyecto del Lab de POO de una tienda de coleccionables, ropa, juegos, etc sobre el mundo del anime de pokemon, anteriormente llamada pelupoke (peluches de pokemon)

## Estructuracion

Página pública: `index.html`  
Inicio de sesión: `login.html`  
Registro de una cuenta: `register.html`  
Tienda despues de registrarse: `home.html`  
Perfil de tu cuenta que creaste: `perfil.html`

## Tablas en Supabase

Se implemento las tablas siguientes tablas para controlar el stock de cada producto

- `profiles`
- `products`
- `purchases`
- `purchase_items`

## Funciones que se implementaron en esta versión final

- Catálogo desde Supabase con búsqueda y filtros por categoría.
- Selector iPhone/Samsung para la funda de Gengar.
- Registro actualizando pidiendo datos de contacto y dirección.
- Login que pida el correo y contraseña con el que se registro
- Perfil editable.
- Menú de usuario y cierre de sesión.
- Actualización de existencias después de la compra.
- FAQ.
